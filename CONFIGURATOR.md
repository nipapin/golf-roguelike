# Castle Studio — локальный конфигуратор

Двойной щелчок по **Запустить конфигуратор.cmd** открывает http://127.0.0.1:5173/configurator.html в браузере. Сервер работает в фоне. Повторный запуск открывает тот же сервер. **Запустить игру.cmd** открывает игру. На этом ПК зависимости уже установлены; для нового ПК нужен Node.js и `npm ci`.

1. Выберите раздел и элемент. В «Звуки и музыка» доступны все 37 звуковых событий и отдельно музыка меню и боя, в том числе события старых сцен.
2. Прослушайте звук или посмотрите изображение. Для звуков можно выбрать файл из библиотеки, настроить относительную громкость, скорость/высоту или отключить событие.
3. Нажмите «Выбрать новый файл» или перетащите его в область загрузки. Допускаются изображения, SVG, MP3/OGG/WAV/M4A, шрифты и JSON. Лимит одного файла — 30 МБ.
4. Нажмите **Сохранить**. **Проверить в игре** сохраняет текущие изменения и запускает игру внутри окна конфигуратора. Кнопки **ПК / Телефон** переключают размер предпросмотра. Для полноценного широкого экрана откройте конфигуратор в широком окне браузера или запустите **Запустить игру.cmd**. Для уже открытой игры в другом окне обновите страницу.

Громкость событий задаётся относительно игрового микса. Ползунки звуков и музыки в самой игре продолжают действовать. Предпросмотр воспроизводит файл без игрового микшера, фильтров и звуков других событий; итоговую громкость проверяйте в игре. Изменение скорости звука меняет также высоту тона. Музыка в меню по-прежнему приглушается игровым фильтром.

«Графика игры» содержит рабочие изображения, эффекты, монету и иконки. PNG-исходники, старые персонажи и другие резервные материалы находятся в «Архив и исходники»: их замена не меняет активный режим игры. «Все файлы» показывает все медиафайлы и JSON в public. Текстовые лицензии и документация не являются игровыми ассетами.

Карты и часть интерфейса рисуются кодом, поэтому отдельного изображения для них нет. Раздел «Цвета интерфейса» позволяет менять их палитру. Изменение формы карт, расположения интерфейса или анимаций требует правки кода.

Изображения персонажей и построек сохраняют заданную игровую высоту независимо от разрешения замены. Для хорошего результата используйте прозрачный фон и минимальные пустые поля вокруг объекта. Эффекты используют атласы: изображение и JSON должны совпадать по размерам, координатам и именам кадров. Смена раскладки требует замены обоих файлов. JSON других каталогов редактируется как файл; автоматического создания анимаций нет.

## Где хранятся изменения

- `public/game-assets.json` — настройки и ссылки на замены. Изменения включаются в `npm run build` и работают в собранной игре.
- `public/assets/custom/` — загруженные файлы, оригиналы не перезаписываются.
- `.local/asset-config-backups/` — предыдущая версия конфига перед каждым сохранением.
- `.local/configurator-server.log` — журнал локального сервера.

«Восстановить этот элемент» и «Восстановить всё» выбирают исходные настройки. Нажмите «Сохранить» для применения. Загруженные файлы остаются на диске.

Экспорт/импорт переносит JSON настроек. Для переноса на другой ПК скопируйте также папку `public/assets/custom/` или весь проект. Файлы не встраиваются в JSON. При отсутствующих файлах сохранение пресета отклоняется. Если конфиг изменён в другом окне, сохранение блокируется до обновления страницы, чтобы не затереть чужие изменения.

Конфигуратор доступен через `npm run dev` / `npm run configurator`; он предназначен для локальной работы на ПК. В production-сборку входит игра и сохранённые ассеты. Интерфейс записи файлов не публикуется.

Чтобы остановить фоновый сервер: `powershell -NoProfile -ExecutionPolicy Bypass -File .\Остановить сервер.ps1`. Скрипт останавливает только Vite, запущенный стартовым скриптом из этой папки.
