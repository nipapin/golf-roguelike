# Дополнительные анимации, версия 1

PNG созданы встроенным инструментом imagegen по сохранённым игровым референсам.
Исходный экспорт After Effects не изменён. Новые листы пока не заменяют графику в игре.
Это покадровая растровая анимация; слои и ключи After Effects не восстанавливаются.

## Состав

- `knight-extra.png`: idle 0–3, hurt 4–7, dead 8–15.
- `archer-extra.png`: idle 0–3, hurt 4–7, dead 8–15.
- Пушка исключена из этого комплекта: в игре нужен исходный стоп-кадр 39.
- `goblin.png`, `orc.png`, `reaper.png`, `ogre-boss.png`, `reaper-boss.png`:
  walk 0–3, attack 4–7, hurt 8–11, dead 12–15.
- Исправленная ходьба гоблина, орка и огра-босса находится в отдельных
  `*-walk-v2.png` (4 столбца × 2 строки, walk 0–7). Каталог связывает действие
  `walk` с этим листом через поле `asset`. Эти дополнительные текстуры
  помечены `hidden`: в предпросмотре они показаны в карточке своего персонажа.
- `animations.json`: каталог действий с диапазонами, частотой и повторением.
- `*.atlas.json`: координаты каждого кадра для `Phaser.load.atlas`.
- `prompts.json`: полные запросы генерации.
- `all-animations.html`: общий каталог новых поз, исходных AE-анимаций и боевых
  эффектов; переключение действий, пауза, скорость и шаг на один кадр.
  У рыцаря и лучника исходные и новые действия собраны в одной карточке.
  Ходьба рыцаря использует авторские AE-кадры 0–15 при 30 fps, атака — 16–36.
  Автоповтор включён для предпросмотра, в том числе для эффектов. Его можно
  отключить; поле `repeat` исходных игровых анимаций не изменено.
- `preview.html`: пустая страница «Недостающие анимации» со ссылкой на каталог.

Основные PNG имеют четыре столбца и четыре строки, листы walk-v2 — четыре
столбца и две строки. Нумерация с нуля, слева направо,
сверху вниз. Фактические размеры записаны в JSON: генератор может вернуть
размер, не кратный четырём, поэтому нужно использовать приложенный атлас,
а не предполагаемый `frameWidth: 384`. Атлас учитывает разницу в один пиксель
между ячейками без изменения пикселей PNG. Границы рядов уточнены по прозрачным
промежуткам; кадры обрезаются координатами атласа и восстанавливаются в общий
виртуальный размер через `sourceSize` и `spriteSourceSize`. Изолированные
фрагменты соседнего персонажа у края не входят в прямоугольник основного спрайта.

## Предпросмотр

При запущенном dev-сервере игры:
http://127.0.0.1:5191/assets/generated-animations-v1/all-animations.html

Копия комплекта лежит в `golf-roguelike/public/assets/generated-animations-v1/`.

## Пример Phaser

```ts
// preload()
this.load.atlas('knight-extra',
  '/assets/generated-animations-v1/knight-extra.png',
  '/assets/generated-animations-v1/knight-extra.atlas.json');

// create()
this.anims.create({
  key: 'knight-extra-dead',
  frames: this.anims.generateFrameNames('knight-extra', {
    prefix: 'frame-', start: 8, end: 15, zeroPad: 4,
  }),
  frameRate: 10,
  repeat: 0,
});
```

Перед объединением с AE-анимациями нужно сопоставить масштаб и опорную точку
в кадре: сгенерированные позы не имеют того же рига, что исходные AE-слои.
Последний кадр смерти удерживается; переход обратно к idle не нужен.
