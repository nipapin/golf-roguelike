# Этап: воспроизводимый бой и безопасное продолжение

Работа основана на аудите PR #1 от 25 сентября 2026 года, но выполнена поверх
`main` на коммите `0fd9265`: PR #2 и #3 уже внедрили core, сцены, seeded RNG и
сохранение. Повторная реконструкция этих частей не требуется.

## Закрытые пробелы

- BattleScene сохраняет CardVisual по ID. После play уничтожается только снятая
  карта; при draw обновляются доступность и состояния существующих карт.
- Спрайт врага, shadow, имя и HP bar сохраняются между действиями. Обновление
  состояния больше не прерывает его анимацию уничтожением спрайта.
- Фон не перерисовывается на каждом действии. Активная карта обновляется только
  при смене ID. Resize перезапускает представление, не изменяя игровой state;
  shutdown снимает listener и очищает ссылки перед повторным входом.
- Карточная hit zone переиспользуется и корректно включается/выключается.
- Load проверяет структуру run/battle/player/enemy/cards, фазу, диапазоны и
  уникальность всех 52 физических карт. Повреждённые и несовместимые сохранения
  удаляются; CONTINUE доступен только для валидного сохранения версии 1.
- RNG state ограничен uint32. Старые числовые состояния нормализуются без смены
  последующей последовательности генератора.
- Очистка tableau подготавливает награды до сохранения и перехода экрана.
  GameManager возвращает именно сохранённое состояние, включая награды.
- Отклонённый play не пишет сохранение и не отправляет события.
- Исправлены HEAL/GUARD/GOLD: случайно назначенные power-карты применяют эффект
  на любой масти. Существующие числовые значения не менялись.
- Удалены неиспользуемые объявления, мешавшие штатному lint.

## Проверки

- `npm test`: 76 тестов проходят. Включены реальные вызовы SaveService с
  продолжением ходов и дальнейшим потреблением RNG, неизменность входного state,
  повреждённые сохранения, награды при очистке tableau и все масти для powers.
- `npm run lint`: проходит, остаются четыре существующих предупреждения `any`.
- `npm run build`: проходит; существующее предупреждение о размере Phaser bundle.
- Тесты представления проверяют идентичность объектов и фиксированные позиции
  после play/draw; Phaser-компоненты в этих unit-тестах заменены doubles.
- `npx playwright test tests/e2e/battle-resume.spec.ts --list`: обнаружены три
  мобильных сценария (375×667, 390×844, 430×932).
- Browser E2E не выполнен: Chromium не установлен, загрузчик получает повреждённый
  ZIP. Для проверки в среде с доступным браузером:

```sh
npx playwright install --with-deps chromium
npm run build
npx playwright test tests/e2e/battle-resume.spec.ts
```

E2E проверяет реальный tap доступной карты, сохранение, reload/CONTINUE и draw.
Визуальная проверка на iOS и этот браузерный прогон остаются перед merge.

## Граница этапа

Не добавлены новый контент, арт, juice или системы анимаций. Сохранены правила,
уже объединённые в PR #2/#3: A↔K, one-use WILD, накопление chain damage до draw,
атака на draw, reshuffle и сброс armor. Предложения исходного аудита не применялись
как новые решения баланса. Не объявляем весь roadmap 0–7 завершённым.
